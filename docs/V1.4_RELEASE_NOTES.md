# V1.4

This is a conservative reliability release of the existing MQTT 3.1.1 client.

- Fix QoS 1 PUBACK recognition and the `publish_acknowledge` signal.
- Give PUBACK and PUBREC their correct names and opcodes.
- Wrap packet identifiers through the valid range 1–65535.
- Reject unsupported QoS 2 operations explicitly.
- Validate packet lengths derived from network input in release builds.
- Stop processing an unlimited number of packets in one frame.
- Report socket read and TLS failures through the connection state.
- Add editor-friendly deterministic tests and opt-in public broker checks.

The simulated LAN broker is deliberately not part of this release. It will be
built on top of the tested client and packet behaviour in a later milestone.
